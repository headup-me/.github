# Security policy

Report security problems privately, never in a public issue, pull request or discussion.

- **In a public repository** ([website](https://github.com/headup-me/website),
  [help](https://github.com/headup-me/help), [legal](https://github.com/headup-me/legal),
  [design](https://github.com/headup-me/design) or this one): use **Report a vulnerability** in the
  repository's **Security** tab.
- **Anything else**, including the apps, the API, or a problem you cannot place: write to
  contact@headup.me.

Include what you found, how to reproduce it and what it affects. Head Up reviews every report.
