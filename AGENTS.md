# AGENTS

If you act for Head Up and your context does not contain the block that starts with the heading
"Head Up org rules" and ends with the line "End of Head Up org rules", say so in your first reply and
work read-only (no file edits, commits, pushes, pull requests or Issues) until the owner answers.

Organization-wide rules for Head Up agents come from the handbook. This file adds only what is
specific to this repository.

## What this repository is

The `.github` repository of the headup-me organization. `profile/README.md` is the organization's
public profile on GitHub. The other files are the default community health files and templates that
every headup-me repository without its own inherits: `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`,
`PULL_REQUEST_TEMPLATE.md` and `ISSUE_TEMPLATE/`.

## Rules

- A change here changes the defaults of every repository that has no file of its own. Make it only
  on the owner's request.
- The profile names and links only public repositories and public pages.
