## Open repositories

| Repository | What it holds |
| --- | --- |
| [website](https://github.com/headup-me/website) | The public website at [headup.me](https://headup.me). |
| [help](https://github.com/headup-me/help) | The help center: short guides in English and Spanish. |
| [legal](https://github.com/headup-me/legal) | The privacy policy, the child privacy notice and the terms of service, with every change in the open. |
| [design](https://github.com/headup-me/design) | The design system: design tokens, Vue components, fonts and brand assets. |

The API and the web and mobile apps are developed in private repositories.

## Contributing

- **A guide is wrong, unclear or missing a language?** Open an issue or a pull request in
  [help](https://github.com/headup-me/help).
- **A question about a legal text?** Open an issue in [legal](https://github.com/headup-me/legal).
  Head Up makes the changes to the texts.
- **A security problem?** Report it privately, as the
  [security policy](https://github.com/headup-me/.github/blob/main/SECURITY.md) describes.
